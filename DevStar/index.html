02 / SOBRE

Uma página é formada por caixas.

Quando começamos a trabalhar com CSS, entender como essas caixas se comportam é fundamental para construir bons layouts.

BOX

Box Model

Todo elemento possui uma área de conteúdo, preenchimento, borda e margem.

Controlando essas partes podemos definir o espaço ocupado pelos elementos da página.

03 / ORGANIZAÇÃO

Conteúdo e posicionamento

Algumas propriedades permitem alterar a forma como os elementos ocupam espaço na página.

CSS

A propriedade float permite posicionar um elemento à esquerda ou à direita, fazendo com que o texto seguinte ocupe o espaço ao seu redor.

Esse comportamento foi muito utilizado na construção de layouts e ainda pode ser útil para situações como imagens inseridas dentro de textos.

Este conteúdo aparece depois do elemento flutuante.
